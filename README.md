# Alien Invasion Preview
![project preview](images/project_preview.png)

## Run
    pip install pygame
    python alien_invasion.py

## Controls
- Move: Arrow keys or WASD
- Shoot: Space
- Quit: Q or ESC

## Features Integrated
- Up / Down Movement
- Starry Space Background
- Debug button (bottom right): skips to the next wave
- Boss Alien (spawns every third round)
